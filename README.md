# Flappy Bird - Unity

A 2D Flappy Bird-style arcade game developed using Unity 6.6 and C#.

## Features

- Bird movement and gravity-based physics
- Pipe spawning and movement
- Collision detection
- Score system
- Persistent high-score system
- Dynamic difficulty based on player score
- Play screen and game-over screen
- Restart functionality
- Moving cloud background with looping
- Sound effects for flap, scoring, and game over
- PC controls using keyboard/mouse
- Android touch controls

## Controls

### PC
- Space / Left Mouse Click - Flap

### Android
- Tap the screen - Flap

## Built With

- Unity 6.6
- C#
- Unity 2D Physics
- Unity UI
- Audio System

## Project Structure

- `Assets/` - Game assets, scripts, scenes, sprites, sounds and UI
- `Packages/` - Unity package configuration
- `ProjectSettings/` - Unity project settings
